# 1C-Mail

Приложение для Windows с веб-интерфейсом (HTML GUI), которое принимает печать
из 1С как **виртуальный принтер**, сохраняет документ в PDF и автоматически
отправляет его по электронной почте клиенту.

Адрес клиента определяется по реквизитам напечатанного документа — **название
организации** и **УНП** (белорусский учётный номер плательщика) — и подбирается
из базы, которая пополняется при каждой отправке и хранится отдельно от
программы, поэтому при обновлении новая версия сразу подхватывает накопленные
данные.

## Как это работает

```
1С ──печать──▶ виртуальный принтер «1C-Mail»
                     (драйвер «Microsoft Print to PDF» + файловый порт
                      %ProgramData%\1C-Mail\spool\capture.pdf)
                        │
                        ▼
              Electron-приложение (фоновый наблюдатель)
                        │
          ┌─────────────┼─────────────────────┐
          ▼             ▼                     ▼
    извлечение текста   разбор реквизитов    поиск клиента
    (pdfjs-dist, PDF)   (УНП/название/email)  в базе (вне программы)
                        │                     │
                        └─────────┬───────────┘
                                  ▼
                        отправка по SMTP (nodemailer)
```

- **Виртуальный принтер** устанавливается NSIS-инсталлятором (скрипты
  `scripts/install-printer.ps1` / `uninstall-printer.ps1`) и при необходимости
  из самого приложения (кнопка «Установить принтер»). Используется штатный
  драйвер «Microsoft Print to PDF» и фиксированный файловый порт, поэтому никаких
  сторонних драйверов не требуется; принтер можно сделать **общим**, чтобы 1С с
  других машин печатала в него по сети.
- **Данные** (настройки, база клиентов, журнал, spool) хранятся в
  `%ProgramData%\1C-Mail` — вне каталога установки. При обновлении/переустановке
  программы данные **не удаляются** и подхватываются автоматически.

## Требования

- Windows 10/11 или **Windows Server** (2016/2019/2022).
- Компонент Windows «Microsoft Print to PDF» (включается скриптом установки).
- Доступ к SMTP-серверу для отправки почты.

## Сборка (GitHub Actions)

Сборка `setup.exe` выполняется **только на GitHub** через
`.github/workflows/build.yml` на Windows-раннере:

- при каждом `push` — прогон тестов (`npm test`) и сборка NSIS-инсталлятора;
- артефакт `dist/1C-Mail-Setup-<версия>.exe` выкладывается как GitHub Artifact;
- при пуше тега `v*`（например `v1.0.0`) поверх этого создаётся GitHub Release с
  прикреплённым `setup.exe`.

Чтобы собрать релиз:

```bash
git tag v1.0.0
git push origin v1.0.0
```

Локально для разработки:

```bash
npm install
npm test          # юнит-тесты (node:test)
npm start         # запуск приложения (Electron)
npm run dist      # сборка инсталлятора (требует Windows)
npm run gen-fixture  # перегенерация тестового PDF-образца
```

## Использование

1. Установите `1C-Mail-Setup-<версия>.exe` (от имени администратора).
2. Откройте приложение, перейдите в **Настройки**:
   - **SMTP-сервер** — данные почтового ящика (хранится в `%ProgramData%\1C-Mail`).
   - При желании нажмите «Тестовое письмо».
   - Нажмите «Установить принтер» (если не установлен инсталлятором).
3. В 1С в диалоге печати выберите принтер **«1C-Mail»**.
4. Документ попадёт в приложение, реквизиты распознаются, клиент ищется в базе:
   - если клиент найден и включена автоотправка — письмо уходит автоматически;
   - иначе документ появляется во вкладке **«Отложенные»**, где нужно подтвердить
     адрес (и при необходимости выбрать клиента из базы).
5. База клиентов растёт сама по себе при каждой отправке; её можно
   редактировать, импортировать/экспортировать в CSV (кодировка UTF-8 с BOM для
   Excel).

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `src/main/main.js` | главный процесс Electron, оркестрация, IPC |
| `src/main/extract.js` | извлечение текста из PDF и разбор реквизитов (pdfjs-dist) |
| `src/main/match.js` | сопоставление реквизитов с базой клиентов |
| `src/main/store.js` | хранение данных вне программы (JSON в `%ProgramData%\1C-Mail`) |
| `src/main/mailer.js` | отправка письма по SMTP (nodemailer) |
| `src/main/watcher.js` | наблюдение за файлом захвата печати |
| `src/main/printer.js` | управление виртуальным принтером через PowerShell |
| `src/renderer/*` | HTML GUI (index.html, styles.css, app.js, иконки) |
| `scripts/*.ps1` | установка/удаление/статус виртуального принтера |
| `build/installer.nsh` | кастомные секции NSIS (принтер при установке) |
| `tests/` | юнит-тесты (`node --test`) + тестовый PDF-образец |
| `resources/sample-invoice.pdf` | образец документа для сквозного теста |
